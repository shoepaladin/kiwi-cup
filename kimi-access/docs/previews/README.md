# Previews

Every PR in this project that changes anything graphical — widgets, settings
screens, icons, themes, layouts — must include a visual record:

1. A self-contained `before-after.html` in this directory rendering OLD vs NEW
   side by side for every mode the PR touches (inline SVG/CSS only, no external
   assets, so it renders straight from the repo).
2. Low-resolution screenshots of that page embedded in the PR body — small
   JPEGs (~620px wide, ~15–25KB each) are enough; the goal is the gist of the
   change, not retina fidelity.

Keep total image weight per PR under ~100KB.
